# LibraryController

A JS-only program developed to help people manage better their libraries!

## Overview

**LibraryController** is a simple and flexible JavaScript application designed to help users organize and manage their book collections more efficiently. Whether you're a student, librarian, or book enthusiast, LibraryController provides the essential tools to keep track of your library with ease.

## Features

- 📚 **Add, edit, and remove books** from your collection
- 🔍 **Search and filter** books by title, author, or other attributes

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gabrielEFagundes/LibraryController.git
   cd LibraryController
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the program:**
   - For Node.js: run the main JS file (`node app.js`)

## Usage

- Add books by entering their details (title, author, genre, etc.)
- Use search and filter options to find books quickly
- Update or delete book entries as needed
